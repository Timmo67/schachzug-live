# Start mit Claude Code

## Einmalig einrichten
1. Kostenloses GitHub-Konto anlegen (github.com), falls noch keins da ist.
2. Neues **privates** Repository `schachzug-live` anlegen und den Inhalt dieser ZIP-Datei hochladen
   ("Add file" → "Upload files", alle Dateien und Ordner hineinziehen).
3. claude.ai/code öffnen (oder die Claude-App → Code), GitHub verbinden und das Repository `schachzug-live` wählen.

## Erster Auftrag (kopieren und einfügen)
> Lies CLAUDE.md, docs/KONZEPT.md und docs/ROADMAP.md. Erkläre mir dann in 5 Sätzen auf Deutsch, wie du vorgehst, und starte mit Meilenstein M0. Wenn du ein Konto oder eine Entscheidung von mir brauchst, halte an und sag mir genau, was ich tun soll.

## Danach
Pro Meilenstein ein Auftrag, z. B.:
> Setze Meilenstein M1 aus docs/ROADMAP.md um. Arbeite auf einem eigenen Branch und eröffne am Ende einen Pull Request mit einer kurzen deutschen Zusammenfassung.

Was du selbst erledigen musst (Konten, Geld, Recht): steht in der Roadmap bei „Auftraggeber muss“.
